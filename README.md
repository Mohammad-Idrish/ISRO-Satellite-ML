# 🛰️ ISRO Satellite Image Classification using CNN

## 📌 Project Overview
This project classifies real satellite images into 10 different 
land cover categories using a Convolutional Neural Network (CNN).
Built as part of preparation for ISRO SAC (Space Applications 
Centre) internship in Ahmedabad.

## 🎯 Results
- **Dataset:** EuroSAT RGB (27,000 Sentinel-2 satellite images)
- **Classes:** 10 land cover types
- **Accuracy:** 90% in just 15 epochs
- **Model:** Custom CNN (3 Conv layers)
